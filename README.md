# 帳跡 LedgerTrail｜可追溯會計與控制工作台

正式名稱為「帳跡 LedgerTrail」，工程名為 AAAS-TW／AAAS。

**把來源、會計處理、覆核、過帳、更正與交付連起來，讓人查到數字的依據、處理者、使用版本及未解問題。** 產品方向是由會計師／記帳士主導的中小企業流程；不以 AI 建議代替專業判斷。

> **這是完整私人系統的作品集，不是全部原始碼。** 公開的政策函式只是其中一個可重跑樣本；系統全貌還包括組織與平台治理、案件、科目版本、資料庫控制、背景工作、證據及故障恢復。

## 我的角色與 AI 分工

我以會計背景定義問題與控制目的、選擇範圍、提出驗收要求，並檢視 AI 回報與證據；實際操作遇到反例時再要求修正。具體例子是要求減少來源重抄、讓拒絕說明可定位，以及保留原錯誤案件而不是改成成功，見[需求與分工](docs/CASE_STUDY.md#contribution)。

AI 協助程式實作、文件同步、測試及證據產出。我尚未親自完整重跑或獨立驗證整套系統；工程產物不等於我獨力撰寫全部程式，也不以系統大小推定個人職級。

## 執行公開模組測試

需要 Python 3.11 以上，工作目錄為本庫根目錄：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-test.txt
python -m pytest -q
```

Windows PowerShell 改用 `.venv\Scripts\Activate.ps1` 啟用環境。模組只用標準函式庫，測試使用 pytest 9.0.2，無須資料庫或外部服務。原紀錄為 Python 3.12.14 下 **112 項通過**；本次不改模組、不將舊結果刷新成新測試。

本庫不能啟動完整工作台；畫面屬私人系統的指定合成案例。使用範圍見 [LICENSE](LICENSE)。
