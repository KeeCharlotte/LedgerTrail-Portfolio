# 帳跡 LedgerTrail｜可追溯會計與控制工作台

正式名稱為「帳跡 LedgerTrail」，工程名為 AAAS-TW／AAAS。

**把來源、會計處理、覆核、過帳、更正與交付連起來，讓人查到數字的依據、處理者、使用版本及未解問題。** 產品方向是由會計師／記帳士主導的中小企業流程；AI 可提供候選或文件調查，不代替專業判斷及入帳授權。

> **這是完整私人系統的作品集，不是全部原始碼。** 公開政策函式只是其中一個可重跑樣本；系統還包括組織與平台治理、案件、科目版本、資料庫控制、背景工作、證據與故障恢復。

> **目前界線（2026-10-28 盤點）：** 已有受控 Gemini 合成會計候選、Financial Insight v2、預設 v5 的交易證據調查與具名交接包離線檢查。仍限受監督的合成資料開發／測試；引用分欄尚有已知限制，沒有完整真實月份、專業採信或正式上線資格。詳見[目前狀態](docs/STATUS.md#known-limitations)。

## 我的角色與 AI 分工

我以會計背景定義問題與控制目的、選擇範圍、提出驗收要求，並檢視 AI 回報與證據；實際操作遇到反例時再要求修正。具體例子是減少來源重抄、讓拒絕說明可定位，以及保留原錯誤案件而不是改成成功，見[需求與分工](docs/CASE_STUDY.md#contribution)。

2026-10-01～02，我親自執行公開樣本、部分私人測試命令與結果核對，並完成九項介面操作，發現證據錯配反例。AI 協助程式實作、環境除錯、後續自動化與證據整理；不代表全部程式或驗證由我獨立完成，也不等於獨立第三方審查。後續 AI 工程內容覆核與真人／專業接受仍分開。

## 執行公開模組測試

需要 Python 3.11 以上，工作目錄為本庫根目錄：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-test.txt
python -m pytest -q
```

Windows PowerShell 改用 `.venv\Scripts\Activate.ps1` 啟用環境。模組只用標準函式庫，測試使用 pytest 9.0.2，不需要資料庫或外部服務。程式與測試仍保留原來源 `4841c001`，並已與本次私人基準逐檔核對相同；112 項樣本案例不驗收完整權限、資料庫過帳、AI 或專業適用性。本次執行結果與環境見[驗證摘要](evidence/ENGINEERING_SUMMARY.json)。

本庫不能啟動完整工作台；[歷史畫面與 CSV](docs/CASE_STUDY.md#historical-demo)仍屬原版本合成案例，不是目前介面截圖。使用範圍見 [LICENSE](LICENSE)。
