### 已修範圍與仍未成立的條件

M02 在 10/03 已取得**固定模板**的內容一致性修復與 31 項 PostgreSQL 回歸；金額原值的精度／有限性修復亦已納入會計套件。原 10/02 錯配仍作歷史反例保留，不寫成從未發生。

M05 仍不能由這些技術檢查結案：勾選、HTTP 取件與 reviewed ID 不證明實際閱讀、理解或比對；短說明被接受也不證明交付內容充分。未知文件格式仍走受控人工路徑，銀行解析仍有信任邊界；這不是通用 OCR、真銀行接入或專業認列驗收。

正式 status 仍有指定互動會計工作區端到端、正式觀測、還原演練、效能／安全審查與外部信任等未觀察／未成立範圍。因此不是「本地都完成，只差一張認證」。10/03 原 Windows 匯出工具的 5 個環境／檔案操作錯誤也保留；它與 fast 是不同測試，不以 Linux 補證宣稱 Windows 工具已修好。

## 4. 剩餘工作的完成條件

| 工作 | 還需要成立什麼？ |
| --- | --- |
| 擴大業務與人工驗收 | 在已修固定模板範圍之外，取得真實來源、專業政策及指定真人工作流程證據；不由單一修復推定全會計核心正確。 |
| 驗證與平台缺口 | 保留 10/03 的成功、原失敗及 SKIP；處理仍存在的 Windows 匯出工具限制與 status 未觀察範圍。來源變更後再做相稱驗收，不換掛舊 PASS。 |

| 真實資料接入 | 選定來源，完成解析、收件保存與轉接；保留原件、差異及人工確認，不把候選升格成事實。 |
